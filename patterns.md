# DSA Patterns

This file contains the important problem-solving patterns I learn during my DSA journey.

## 1. Arrays

### Two Pointers
- Used when working with elements from both ends of an array.
- Common idea: one pointer starts from the beginning and another from the end.
- Example: Reverse an Array
- Time Complexity: O(n)
- Space Complexity: O(1)

### Subarrays
- A subarray is a continuous part of an array.
- Example: Print Subarrays
- Important idea: use nested loops to generate all continuous subarrays.

### Buy and Sell Stock
- Track the minimum buying price seen so far.
- Calculate the profit for each current price.
- Keep the maximum profit.
